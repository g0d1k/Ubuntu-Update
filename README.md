This is a simple update script for Ubuntu that will update apt cache, upgrades and updates for snap. Also will run auto remove to remove unused files. Edit this file as needed if you have any other distro. 

- run 'sudo git clone https://github.com/g0d1k/Ubuntu-Update.git'
- 'cd Ubuntu-Update'
- 'sudo chmod +x update.sh'
- 'sudo ./update.sh'
